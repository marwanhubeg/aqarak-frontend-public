# 🌐 الواجهة الأمامية لتطبيق عقارك الذكي (React PWA)

هذا المستودع يمثل الواجهة الأمامية (Web App) لمنصة **عقارك الذكي (Aqarak.ai)**، وهو تطبيق ويب تقدمي (Progressive Web App - PWA) تم تطويره باستخدام React. يهدف هذا التطبيق إلى توفير تجربة مستخدم سلسة وفعالة للبحث عن العقارات وإدارتها، مع الاستفادة من قدرات الذكاء الاصطناعي الكمي.

## نظرة عامة على المشروع

تطبيق الويب هذا هو جزء أساسي من حزمة التسليم النهائية لنظام عقارك الذكي المتكامل، والذي يشمل أيضاً قاعدة بيانات، خادم خلفي، مكونات ذكاء كمي، وتطبيق هاتف محمول.

## سبب ظهور الصفحة بيضاء على GitHub Pages

تطبيق الويب هذا مبني باستخدام React ويتطلب عملية بناء (build process) لتحويل الكود المصدري إلى ملفات HTML و CSS و JavaScript جاهزة للنشر. عند استضافته على GitHub Pages، يجب التأكد من أن الملفات المبنية هي التي يتم نشرها، وليس الكود المصدري مباشرة. ظهور الصفحة بيضاء يشير عادةً إلى أن تطبيق React لم يتم بناؤه أو تهيئته بشكل صحيح للنشر على GitHub Pages.

### خطوات مقترحة لتفعيل GitHub Pages لتطبيق React:

1.  **تكوين `homepage` في `package.json`**: أضف السطر التالي إلى ملف `package.json`:
    ```json
    "homepage": "https://marwanhubeg.github.io/aqarak-frontend-public/"
    ```
2.  **تثبيت `gh-pages`**: قم بتثبيت الحزمة `gh-pages`:
    ```bash
    npm install --save-dev gh-pages
    ```
3.  **إضافة أوامر النشر إلى `package.json`**: أضف الأوامر التالية إلى قسم `scripts`:
    ```json
    "scripts": {
      "predeploy": "npm run build",
      "deploy": "gh-pages -d build"
    }
    ```
4.  **النشر**: قم بتشغيل أمر النشر:
    ```bash
    npm run deploy
    ```
5.  **إعدادات GitHub Pages**: تأكد من أن GitHub Pages مضبوطة للنشر من فرع `gh-pages`.

## أوامر التشغيل (للتطوير المحلي)

لتشغيل تطبيق الويب محلياً، انتقل إلى مجلد `web-app` (أو المجلد الحالي إذا كان هذا هو المستودع الوحيد) ثم:

```bash
cd web-app # إذا كان هذا المستودع جزءاً من نظام أكبر
npm install
npm run dev
```
